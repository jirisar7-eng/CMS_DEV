## Normative Rules
## 1. Separation of Responsibilities
- Human Architect: System owner, authoritative decision maker, final approver.
- ChatGPT: Governance architect, rulebook author, task capsule formulator, independent audit and security reviewer.
- AI Studio: Bounded implementation engine executing exact task capsules and technical verification.

## 2. Handoff & Governance Integrity
- Tasks are transferred via structured capsules with explicit parent lineage and SHA pinning.
- Handoff reports must contain verifiable evidence (exact remote commit SHAs, CI results, diff firewalls).
- Unilateral reinterpretation or loosening of governance gates is prohibited.
